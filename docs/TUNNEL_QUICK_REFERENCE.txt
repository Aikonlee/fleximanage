                              📝 HOW TO CREATE
═══════════════════════════════════════════════════════════════════════════════

Web UI Method:
  1. Login → https://manage.miwide.com:3443
  2. Navigate to "Devices" page
  3. Select ≥2 devices (checkboxes)
  4. Click "Create Tunnels" button
  5. Choose topology: "Full Mesh" or "Hub and Spoke"
  6. Click "Create Tunnels"
  7. Wait 30-60 seconds
  8. View results in "Tunnels" page

API Method:
  POST https://manage.miwide.com:3443/api/devices/apply
  
  Headers:
    Authorization: Bearer YOUR_TOKEN
    Content-Type: application/json
  
  Body:
    {
      "method": "tunnels",
      "devices": {
        "device_id_1": true,
        "device_id_2": true
      },
      "meta": {
        "tunnelType": "site-to-site",
        "topology": "fullMesh",      // or "hubAndSpoke"
        "hub": null,                 // or hub device ID
        "advancedOptions": {
          "routing": "ospf"
        }
      }
    }
